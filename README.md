## 🎯 О проекте

**Hire** — это фронтенд-реализация сайта агентства недвижимости полного цикла: покупка, аренда и продажа жилья. Проект создан как демонстрация современного подхода к вёрстке — компонентная архитектура, строгая типизация, декларативные анимации и полностью переиспользуемый контент, вынесенный из разметки в данные.

### ✨ Особенности

| | |
|---|---|
| 🧩 **9 страниц** | Главная, About, Buying, Renting, Selling, Contact, Login, Sign Up, 404 |
| 🧮 **3 калькулятора** | Ипотека, «Аренда vs Покупка», оценка стоимости жилья |
| 🔐 **Фронтенд-аутентификация** | Регистрация и вход через `localStorage` + Context API |
| 📱 **Адаптивность 320px+** | Проверено на реальных ширинах от 320px до 1536px |
| ♿ **Доступность** | ARIA-атрибуты, клавиатурная навигация, семантическая разметка |
| 🎬 **Анимации** | Scroll-reveal, кроссфейды, параллакс, счётчики — на Framer Motion |
| 🎨 **Дизайн-токены** | Единая палитра и типографика через `@theme` Tailwind 4 |
| 🚀 **Статика** | Полностью статическая сборка, готовая к деплою на GitHub Pages |

## 🚀 Быстрый старт

Требуется **Node.js 18+**.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/skilledify/react-ts-hire.git
cd react-ts-hire

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер → http://localhost:5173
npm run dev
```

### 📜 Доступные скрипты

| Команда | Описание |
|---|---|
| `npm run dev` | Dev-сервер с hot-reload |
| `npm run build` | Продакшен-сборка в `dist/` |
| `npm run preview` | Локальный предпросмотр собранной версии |

## 🧩 Ключевые компоненты

**Header** — sticky-шапка с адаптивной логикой: десктопная навигация от `lg`, бургер-меню для мобильных. Кнопки **Login** и **Sign Up** остаются видимыми на всех ширинах, начиная с **320px**, и дублируются внутри выезжающей панели.

**Gallery** — две независимые колонки с кроссфейдом. Каждое изображение плавно сменяет предыдущее с одновременным медленным зумом (эффект Ken Burns), интервалы разнесены, чтобы колонки не менялись синхронно.

**FeaturedIn** — бесконечная marquee-лента: массив логотипов дублируется, а анимация `translateX(-50%)` создаёт бесшовный цикл. При наведении анимация ставится на паузу.

**Popular** — карусель объектов на нативном scroll-snap. Стрелки прокручивают трек ровно на одну карточку через `scrollBy` — без внешних слайдеровых зависимостей.

**AnimatedNumber** — универсальный счётчик: анимирует число от нуля до целевого значения, когда попадает в область видимости (`useInView`). Поддерживает префиксы, суффиксы и собственный форматтер — используется для метрик, статистики и результатов калькуляторов.

## 🧮 Интерактивные калькуляторы

Все три калькулятора работают полностью на клиенте, без запросов к серверу.

### 💳 Mortgage Calculator — `/buying`
Считает ежемесячный платёж по стандартной аннуитетной формуле с учётом первого взноса, процентной ставки и срока. Показывает ежемесячный платёж, сумму кредита, переплату и общую сумму выплат.

### ⚖️ Rent vs Buy — `/renting`
Сравнивает совокупные расходы на аренду и покупку за выбранный горизонт. Учитывает рост аренды, амортизацию тела кредита, обслуживание, closing-расходы и выручку от продажи жилья. Визуализирует результат двумя полосами и выводит вердикт с расхождением в деньгах.

### 🏡 Value Estimator — `/selling`
Оценка стоимости по четырём параметрам: город, тип недвижимости, состояние и площадь. Формула строится из индекса цены за м², умноженного на коэффициенты типа и состояния, и выдаёт точечную оценку с доверительным диапазоном ±5%.

## 🔐 Аутентификация

Фронтендовая аутентификация реализована на **Context API** без серверной части.

```
AuthProvider
├── user          — текущий пользователь или null
├── login()       — вход, возвращает { ok, error? }
├── signUp()      — регистрация, возвращает { ok, error? }
└── logout()      — выход
```

**Хранение:** пользователи и сессия сохраняются в `localStorage` под ключами `hire.users` и `hire.session`. Пароль попадает в состояние только вместе с записью пользователя, а в сессию и в контекст уходит очищенный от пароля объект.

**Валидация форм:**
- **Login** — корректность email, обязательность пароля
- **Sign Up** — имя, email, пароль от 6 символов, совпадение подтверждения, принятие условий

> ⚠️ Это демонстрационная реализация для портфолио. Хранение паролей в открытом виде в `localStorage` небезопасно и не должно использоваться в продакшене.

## 🎨 Система стилей

Дизайн-токены заданы один раз в [`index.css`](src/index.css) через `@theme` Tailwind 4 и доступны как обычные утилиты (`bg-ink`, `text-accent`, `border-line`).

| Токен | Значение | Роль |
|---|---|---|
| `--color-ink` | `#121b25` | Основной фон |
| `--color-ink-soft` | `#1a242f` | Фон карточек и секций |
| `--color-line` | `#303a44` | Границы |
| `--color-accent` | `#63b59f` | Акцентный цвет |
| `--color-accent-dark` | `#15786c` | Акцент в hover-состояниях |
| `--color-mist` | `#b3bfcd` | Второстепенный текст |
| `--color-cream` | `#f2ebeb` | Основной текст |

**Типографика:** Work Sans (Google Fonts) в весах 400 / 500 / 600.

**Особенности:**
- Жидкая типографика через `clamp()` — заголовки масштабируются плавно, без рывков на брейкпоинтах
- Собственные `@keyframes` для парящих квадратов и marquee-ленты
- Единая кривая сглаживания `[0.22, 1, 0.36, 1]` во всех переходах — визуально согласованные анимации

## 🚀 Деплой

Проект настроен на публикацию на **GitHub Pages**.

```bash
npm run deploy
```

Команда выполняет `predeploy` (сборку в `dist/`), затем `gh-pages` заливает содержимое `dist/` в ветку `gh-pages`.

### ⚙️ Конфигурация путей

Так как приложение публикуется в подкаталог (`/react-ts-hire`), базовый путь задан в двух местах:

```ts
// vite.config.ts — для статики и index.html
export default defineConfig({
  base: '/react-ts-hire',
})
```

```tsx
// src/App.tsx — для клиентской маршрутизации
<BrowserRouter basename="/react-ts-hire">
```

Пути к изображениям из `public/` собираются через хелпер [`asset()`](src/constants/global.constants.ts), который подставляет `import.meta.env.BASE_URL`. Это необходимо, потому что Vite перезаписывает абсолютные пути только в `index.html`, но **не** внутри JSX и инлайновых стилей:

```tsx
src={asset('/img/hero.jpg')}   // ✓ '/react-ts-hire/img/hero.jpg'
src="/img/hero.jpg"            // ✗ 404 — ведёт в корень домена
```

## ♿ Доступность и адаптивность

**Адаптивность.** Вёрстка проверена на реальных ширинах от **320px до 1536px** — без горизонтального скролла и переполнения контейнеров. На мобильных кнопки **Login** и **Sign Up** остаются в шапке: под них адаптивно пересчитаны размеры логотипа, бургера и внутренних отступов.

**Доступность.**
- Семантические теги: `header`, `nav`, `main`, `footer`, `section`, `figure`
- Интерактивные элементы имеют `aria-label` (`Open/Close menu`, социальные ссылки)
- Состояния раскрытия передаются через `aria-expanded`
- Ошибки форм помечаются `aria-invalid` и `role="alert"`
- Декоративная графика скрыта от скринридеров через `aria-hidden="true"`
- Блокировка скролла body при открытом мобильном меню
